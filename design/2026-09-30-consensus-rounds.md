# 3인 합의 점검 기록

작성 2026-09-30 · 팀 눈길손길

평가·보완 3회(`2026-09-30-evaluation-rounds.md`)로 v4까지 온 뒤, **세 관점의 검토자가 독립적으로 점검하고 → 제안을 합치고 → 세 명이 모든 후보를 직접 확인해 투표하는** 합의 점검을 반복했다. **2명 이상 채택한 것만 반영**한다.

- 검토자: 보안·사생활 / 안정성·정확성 / 사용성·운영·문서. 각자 저장소를 읽고 테스트를 돌리고, 필요하면 저장소 밖 스크립트로 재현한다 (사용자의 실제 서버와 Tailscale은 건드리지 않음).
- 합치기: 같은 원인·같은 수정을 가리키는 제안을 하나의 후보로.
- 투표: 세 명이 **다른 관점의 후보까지 모두** 코드로 확인하고 채택/보류/거절, 수정 방법 의견을 단다.
- 반영: 채택 항목은 실패하는 테스트를 먼저 만들고 통과시킨다. 핵심 수정은 "수정을 빼면 테스트가 실패하는지" 확인한다. 묶음마다 커밋한다. **계정·기록 같은 사용자 결정은 에이전트가 하지 않고 선택지로 남긴다.**
